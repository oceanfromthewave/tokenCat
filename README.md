# Token Cat

Claude Code / Codex 사용 기록(토큰 숫자만)을 경험치로 바꿔 키우는 도트 고양이. 고양이는 Windows 작업표시줄 위를 걷고, 뛰고, 앉고, 졸고, 그루밍한다.

- 아기 → 새끼 → 어린 → 어른 고양이로 자란다. 고양이 종류 18가지(코리안 숏헤어 8색 + 러시안 블루, 브리티시 숏헤어, 아비시니안, 스코티시 폴드, 페르시안, 샴, 랙돌, 벵갈, 메인쿤, 스핑크스)는 처음에 무작위로 정해지고, 흔한 정도가 다르다.
- 경험치를 얻으면 신나서 뛰어다니고, 한참 조용하면 존다.
- 고양이에 마우스를 올리면 멈춰서 상태(레벨, 경험치)를 보여주고, 클릭하면 폴짝 뛴다. 우클릭 메뉴에서 수집 대상과 자동 실행을 고른다.
- 프롬프트나 코드는 읽지 않는다. 토큰 숫자·ID·시각만 쓰고, 모든 데이터는 내 PC에만 저장한다.

개발: `npm install` → `npm run dev`, 테스트 `npm test`, 설치 파일 `npm run build:win`.
