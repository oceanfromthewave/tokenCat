# Token Cat

Claude Code / Codex 사용 기록(토큰 숫자만)을 경험치로 바꿔 키우는 도트 고양이. 고양이는 Windows 작업표시줄 위를 걷고, 뛰고, 앉고, 졸고, 그루밍한다.

- **성장**: 아기 → 새끼 → 어린 → 어른 고양이로 자라고, Lv.12가 되면 도감에 올라간 뒤 새 고양이가 온다.
- **18종**: 코리안 숏헤어 8색(치즈, 고등어, 턱시도, 검정, 흰색, 치즈 턱시도, 삼색이, 젖소) + 러시안 블루, 브리티시 숏헤어, 아비시니안, 스코티시 폴드, 페르시안, 샴, 랙돌, 먼치킨, 메인쿤, 스핑크스. 처음에 무작위로 정해지고 흔한 정도가 다르다.
- **소품**: Lv.3 목걸이, Lv.6 꼬리 리본, Lv.9 모자를 얻는다.
- **쓰다듬기**: 클릭하면 웃으며 하트가 뜨고 야옹 한다(소리는 끌 수 있다). 마우스를 올리면 이름과 레벨을 보여준다.
- **도감**: 고양이 방(레벨업과 키운 수에 따라 가구와 벽지가 생기고, 고양이가 밥 먹기, 스크래치, 캣타워, 캣휠, 낮잠), 이름 짓기, 최근 7일 경험치, 품종 도감, 다 키운 기록, 내보내기/불러오기, 처음부터 다시 시작.
- **방해하지 않기**: 전체화면 앱(영상, 게임)이 켜지면 숨는다. 고양이가 걸을 모니터를 고를 수 있다. 밤(23시~6시)에는 더 많이 존다.
- **개인정보**: 프롬프트나 코드는 읽지 않는다. 토큰 숫자·ID·시각만 쓰고, 모든 데이터는 내 PC에만 저장한다. 외부 통신은 새 버전 확인뿐이다.

개발: `npm install` → `npm run dev`, 테스트 `npm test`, 설치 파일 `npm run build:win`.

## 설치

[Releases](https://github.com/oceanfromthewave/tokenCat/releases)에서 `TokenCat-Setup-<버전>.exe`를 받아 설치한다. 코드 서명이 없어서 Windows SmartScreen 경고가 뜰 수 있다("추가 정보" -> "실행"). 설치 후에는 새 버전이 나오면 앱이 물어보고, 눌렀을 때만 내려받는다.

## 사용

- 고양이 우클릭: 도감 열기, 수집할 도구(Claude Code / Codex), 소리, 전체화면일 때 숨기기, 모니터 선택, 업데이트 확인, Windows 시작 시 자동 실행, 종료
- 트레이 아이콘 클릭: 고양이 숨기기 / 보이기
